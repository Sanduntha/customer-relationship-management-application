# LeadFlow CRM - Frontend (Client)

This is the React-based frontend for the LeadFlow CRM.

## 🚀 Getting Started

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run Development Server**:
   ```bash
   npm run dev
   ```

3. **Build for Production**:
   ```bash
   npm run build
   ```

## 🛠️ Key Technologies
- **React 19**: Latest React features.
- **Vite**: Ultra-fast build tool.
- **Tailwind CSS 4**: Modern styling with dark mode support.
- **Recharts**: For dashboard visualizations.
- **React Router 7**: For seamless client-side navigation.

## 📁 Structure
- `src/components`: Reusable UI components.
- `src/pages`: Main application pages.
- `src/context`: Authentication and Theme state management.
- `src/services`: API communication layer.
